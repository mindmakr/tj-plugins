# Package requests

Use the issue forms to request new packages for the tinyjump registry:

- **Request a library** — a pure-`.tj` library (dates, money, markdown, validation, formatting).
- **Request a port** — an agent-built port of an existing open-source library, verified against the upstream test suite.
- **Request a bridge** — an MCP plugin, REST/webhook adapter, or native `<Native>` device plugin.

See [docs/registry.md](https://github.com/mindmakr/tinyjump/blob/main/docs/registry.md) for the full design, permission model and review rules.
